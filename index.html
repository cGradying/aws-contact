How to Install in Gmail

  1. Click Copy Clickable Signature for Gmail above (or click Open Clean Copy Page and press Cmd+A then Cmd+C).
  2. Open Gmail → Gear icon → See all settings → General → scroll to Signature.
  3. Click Create new, click inside the signature box, and press Cmd+V.
  4. Select the signature under Signature defaults, scroll down, and click Save Changes.
