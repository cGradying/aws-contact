## Adding More Officers

GitHub Pages serves multiple officers cleanly from subfolders inside this repository:

```text
aws-contact/
├── .nojekyll
├── index.html
├── janvin/
│   ├── signature.html
│   └── assets/
└── <officer-slug>/
    ├── signature.html
    └── assets/
```

1. In **Pixel Banner Studio** → **Email preview**, set **Hosted Base URL (HTTPS)** to:
   `https://cgradying.github.io/aws-contact/<officer-slug>/assets/`
2. Click **Download Gmail Kit (.zip)**, unzip it, and copy its `signature.html` and `assets/` folder into `<officer-slug>/` in this repo.
3. Add a card entry for the officer in `index.html`, then commit and push to `main`.

## Installing in Gmail

1. Open the officer's copy page (e.g. `https://cgradying.github.io/aws-contact/janvin/signature.html`) or use the **Copy Gmail Signature** button on the hub page (`https://cgradying.github.io/aws-contact/`).
2. If using `signature.html`, press **`Cmd+A`** then **`Cmd+C`** in Chrome.
3. Open **Gmail** → **Gear icon (Settings)** → **See all settings** → **General** → **Signature** → **Create new** → press **`Cmd+V`**.
4. Choose the signature under **Signature defaults**, scroll to the bottom, and click **Save Changes**.
